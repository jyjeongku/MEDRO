# MEDRO: Multi-Expert Distributionally Robust Optimization for Out-of-Distribution Generalization (NeurIPS'25)

Official PyTorch implementation of [Multi-Expert Distributionally Robust Optimization for Out-of-Distribution Generalization](https://openreview.net/forum?id=Lz5BUjArK4).

Jinyong Jeong, Hyungu Kahng, Seoung Bum Kim

Note that this project is built upon [SubpopBench](https://github.com/YyzHarry/SubpopBench) and [WILDS](https://github.com/p-lambda/wilds).
