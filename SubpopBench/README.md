## SubpopBench Experiments

Our SubpopBench experiments are built upon [SubpopBench](https://github.com/YyzHarry/SubpopBench) ([Yang et al., ICML 2023](https://proceedings.mlr.press/v202/yang23s.html)).

### Training
```bash
python -m subpopbench.train \
    --algorithm MEDRO \
    --dataset  \
    --data_dir  \
    --output_dir  \
    --output_folder_name  \
    --hparams_seed  \
    --seed 
```
